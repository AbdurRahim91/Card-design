# 🎴 Modern Card Design Gallery & Frozen Ice Slider

A collection of **21 modern, eye-catching HTML & CSS card components**, including an ultra-modern **Frozen Ice Multi-Card Carousel Slider**. Designed for web applications, SaaS dashboards, e-commerce, portfolios, and marketing pages.

---

## 🌟 Highlights

- **21 Production-Ready Card Designs**: 3D holographic cards, frosted glassmorphism, Apple-style bento grids, editorial typography, cyberpunk accents, and more.
- **Frozen Ice Multi-Card Carousel (`card-ice-slider.html`)**:
  - Displays **multiple cards in a single slide view** (3 cards on desktop, 2 on tablet, 1 on mobile).
  - Translucent ice glassmorphism styling (`backdrop-filter: blur(24px)`), refractive gloss sheen, and polar aurora lighting.
  - Interactive frosted glass navigation arrows, dot indicators, and mobile touch swipe support.
- **Interactive Showcase (`index.html`)**: Live iframe previews for every card, search filter by keyword or style, syntax viewer, and one-click code copy.
- **Zero Dependencies**: Pure HTML5, modern CSS3, and vanilla JavaScript.

## 🚀 Getting Started

1. Clone or download the repository:
   ```bash
   git clone https://github.com/AbdurRahim91/Card-design.git
   cd Card-design
   ```
2. Open `index.html` in your browser:
   ```bash
   # Linux
   xdg-open index.html
   # macOS
   open index.html
   ```
3. Open `card-ice-slider.html` directly to preview the multi-card ice slider in full window.
